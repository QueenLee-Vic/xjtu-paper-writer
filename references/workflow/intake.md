# 01 需求分析与模式

## 需求记录

先读对话及可访问材料，再填写下表。小任务只记录相关字段，不强制用户填写问卷。文章类型与操作模式分别判定；“小组报告”不能据此推断是否从零写作。

| 字段 | 记录内容与缺省策略 |
| --- | --- |
| 类型 | 个人实验报告 / 小组实验报告 / 课程论文 / 学术综述；不确定且影响结构时询问 |
| 主题与方向 | 研究对象、课程、问题边界；主题未知且要求写作时询问 |
| 教师要求 | 原文、来源位置及适用范围，不能以默认值覆盖 |
| 字数与篇幅 | 数值、上下限、是否包含摘要/参考文献；未指定不擅自声称达标，按任务复杂度形成适度草稿 |
| 标题与章节 | 固定标题、必需章节、可调整结构；未给时按类型建议 |
| 摘要与关键词 | 要求/禁止/未指定；采用类型默认值，修改与仅排版不自行新增 |
| 参考文献 | 是否要求、格式、数量、时效；引用外部观点时需对应来源，不默认编数量 |
| 图、表与公式 | 必需项、用途及已有材料；未指定只在解释或证据需要时增加 |
| 实验数据 | 已给/部分/未给/不适用，来源、单位与缺失项；缺结果不补造 |
| 模板与案例 | 文件角色、教师正式模板或案例、仅参考格式的范围、可访问状态 |
| 交付格式 | DOCX / 正文 / 局部文本 / 图源等；未指定按当前可用文本交付，不假称有 DOCX |
| 内容保护与模式 | A 从零 / B 修改 / C 仅排版；修改对象、冻结范围、原件位置 |

每项约束用以下记录表达：`字段 | 值 | 领域(内容/格式) | 来源类别 | 来源位置或原话 | 状态 | 决策及理由`。
来源类别区分：用户明确要求、文档提取、Skill 默认。用户转述的教师要求标为“用户明确要求：转述教师”；未经确认的文件属性不能写成教师明确要求。状态区分：明确、已提取、采用默认、关键待定、无法验证。一个字段可保留多条来源，不把被覆盖值删掉。

## 智能确认

已明确的信息不重复询问。缺非关键项用可配置默认值并说明；姓名、学号、组员等不编造，非必需可留空。一次合并当前必要问题，允许用户分批补充，继续不依赖答案的任务。

关键问题包括：无主题却要求写作、无实际数据却要求实验结论、关键单位不明、教师同级要求冲突、格式变更可能损失内容。局部改段落时不为整篇字数、摘要或封面发问。

要求冲突按 [模板机制](../standards/formatting.md) 判定。未确定字数统计口径仅在影响硬性达标时提问；不能把教师要求静默降级为建议。缺模板不阻塞已有默认格式，缺实验数据阻塞实验结果与结论，但不阻塞已有原理及结构整理。

## 模式边界

A 从零：以证据和教师要求建结构；数据不足则交付明确未完成的部分，不编完整实验。

B 修改：先列允许编辑对象（段落、章节、图表或格式），保留无关内容与原格式。用户只说“修改”但未说明问题时，可先检查并指出建议范围；影响观点、数据或结论的修改须有授权与证据。纯语言润色只执行 06 及局部检查。

C 仅排版：正文、数字、公式、数据、图表文字与图片表达信息、参考文献及顺序为冻结基线。可以调整字体、字号、对齐、段落、标题样式、行距、表格线与图片尺寸；图片只能等比缩放且保持可读，不裁剪图例或改变信息。禁止纠错、自动改写、重算数据、重排参考文献、改标题文字或编号。不能保证无损时暂停受影响操作并报告风险；其他安全项可继续。

基线覆盖段落、表格、脚注/尾注、页眉页脚、文本框、公式与图片等实际存在的容器；不支持的对象列为未验证。原件保留，输出另存；可疑事实只列问题，不在仅排版中修正。
