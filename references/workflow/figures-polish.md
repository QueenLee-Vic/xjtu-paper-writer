# 05 智能配图与 06 学术润色

## 配图

配图类型识别、必要性、外部宿主调度、内置绘图和插图合同按需读取 [智能学术配图](figures.md)。已实现独立配图计划、SVG/PNG、结构化数据绘图及显式授权 DOCX 插图；需要数据图或插图时再加载 [科学配图接口](scientific-figures.md)。仅排版与仅润色任务不能自动配图。

## 润色

学术润色的强度、四类文体、任务范围、外部适配与保护审查按需读取 [学术中文润色](academic-polishing.md)。默认标准强度，由当前 Agent 完成语言编辑；Python 负责保护项、占位及差异验证，不将正则替换称为高质量润色。缺外部宿主能力使用内置规则；外部输出也必须审查。

仅排版跳过润色，检查模式只给建议。数字/单位/术语/公式/引用及独立信息、条件、归因和结论强度受保护；自动检查通过还需逐项语义审查。实际 DOCX 局部改文须独立授权，按 [受限写入合同](../standards/docx-polishing-writing.md) 重验计划与逐项语义证据，只改授权文本节点并检查其余包保真，不重建文档。
