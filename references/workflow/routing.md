# 阶段选择、局部返工与停止条件

以需求摘要为路由依据。阶段不是必须逐一执行的流水线；先判定模式、范围和所需能力，再选最小充分集合。每个阶段记录输入、产物、状态（待处理/进行中/完成/阻塞/跳过）及理由。已有阶段完成不代表新输入后仍有效。

| 阶段 | 何时调用 | 产物与回退 |
| --- | --- | --- |
| 01 需求分析 | 每次任务或范围改变，局部任务可简化 | 需求摘要、保护边界、关键待定项；要求变化重新判定范围 |
| 02 模板及案例分析 | 有模板、教师格式要求或需要默认格式 | 分离内容/格式约束及来源；只读目标文件排版时不导入内容 |
| 03 文献与数据 | 需要新证据、核实引用或数据分析 | 来源记录、可追溯结果；来源不足则阻塞相关论断 |
| 04 写作 | 新写、补充或经授权改写 | 目标内容及论证；证据不足回 03，不凭空填补 |
| 05 配图 | 任务要求或论证需要图，且获相应授权 | 数据图或明确示意图；数据错误回 03，概念错误回 04 |
| 06 审校润色 | 新稿或指定文字需语言处理 | 范围内修改及技术保护检查；不借润色改结论 |
| 07 DOCX 排版 | 交付 DOCX 或明确要求格式调整 | 样式规格/实际文档；工具不足给规格，不能称成品 |
| 08 最终检查 | 所有实际产物，包括独立模块 | 仅检查本次范围及相关依赖；标识未验证、阻塞和不适用 |

## 模式与典型路径

- A：01 → 必要的 02/03 → 04 → 按需 05/06/07 → 08。无图无需 05，交付纯文本无需 07；没有模板时 02 仅确定默认值。
- B：01 → 目标阶段及必要依赖 → 08。只改讨论可选 03/04/06；不重写其他章节。修改格式才加载 02/07。
- C：01 → 02 → 07 → 08；禁止进入 03—06。审校发现内容疑点只报告，不自动切换 B。
- 独立模块：润色一段为简化 01 → 06 → 局部 08；单画流程图为简化 01 → 05 → 图源检查；仅分析模板为 01 → 02 → 约束检查，不生成文章。

## 返工与确认

08 发现样式问题返回 07；证据错误返回 03；结构或论证问题返回 04；表述问题返回 06。返工仅在当前授权范围内，更新下游受影响项，不机械重跑全部阶段。C 模式内容差异返回 07 撤销有损操作，不进入写作阶段修复。

要求、材料或修改范围改变时更新 01，只使依赖这些变化的完成项失效。关键冲突或无损风险暂停相关操作，说明阻塞及可继续的部分。某阶段失败不允许无限重试、伪造成功或扩大任务；本次开发仅设计上述规则，不执行未来阶段实现。


涉及格式方案时，可在 02/07 之间按 [配置解析规范](../standards/style-resolution.md) 生成预览；它不是 DOCX 写入步骤。候选、同级冲突或非法高优先级值只阻塞相应属性；用户未确认前不进入其执行集合。修改任务按授权范围过滤；仅排版不得借配置合并开启内容变更。


独立 05 可调用 [配图模块](figures.md) 形成计划，仅生成本次必要且获授权的解释图；B/C/D 按来源门槛登记或阻塞，不能为缺失结果造图。该调用不启用 06 润色；只有用户同时授权文档插图时进入必要的 07 和增量保真检查，遵循 [科学配图接口](scientific-figures.md)。

独立 06 按 [学术润色合同](academic-polishing.md) 明确全文/章节/段落/仅建议范围与轻度/标准/深度，不因深度提高就扩展到未授权段落。format_only 禁止改文；check_language 只报告建议。有文字变化必须在硬保护与语义审查后交付；缺关键证据或含义不确定仅阻塞相关改稿，不自动开启 03/04 补事实。Phase 4B-1 不执行 DOCX 文本写入。

用户请求 DOCX 局部润色准备时，可在 06/08 之间使用 [只读映射与预览](../standards/docx-text-mapping.md)，不自动调用写入器。全文、章节、段落和字符范围都必须显式授权；混合 Run 归属不明或语义未审只交阻塞预览。仅排版、仅建议不能借此获得改文权限。


收到实际 DOCX 润色写入授权且预览及语义证据完整时，06 → [受限局部写入](../standards/docx-polishing-writing.md) → 08；写入器重验全部绑定，只改原文本节点，不自动调用格式/配图模块。复杂对象或格式归属不明交建议；源版本变化退回映射和语义审查。仅检查、仅排版或只要求准备计划不进入写入。输出保真通过后单独渲染，不能将格式属性未变解释为页面不重排。


新写个人/小组实验报告在01/02确定类型及教师结构后，按需加载 [实验报告默认模板](../writing_types/experiment-reports.md)。只选择本次类型的封面与章节；不明确时集中询问，不推断成员。默认只补教师未规定部分，06/07不改变真实性要求；修改/仅排版不因默认扩展新增封面、成员或正文。


## 工作区运行合同

工具须传 `--workspace`，用户文件相对授权工作区解析；规则和资源相对安装根解析。所有原有范围授权、哈希绑定、保护与保真检查继续生效。详细入口见 [安装说明](../../INSTALL.md)。
