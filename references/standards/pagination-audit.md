# 分页保护与检查

扩展既有 format_docx.py / render_docx.py / equation_layout.py，pagination_layout.py 仅为写入器内部助手。所有新产物位于授权工作目录中的新路径，原始DOCX和既有输出保持不变。

## 内容缺项的定位

依次核对当前源文件 SHA256、历史输入副本、输出 DOCX（含非正文 XML）、原始与输出 PDF。检查课程标题时先消除 XML/提取空白，不能只查页数或一个正文字符串。包结构、正文顺序、数学对象、媒体、表格结构和其他部件继续分层比较。

当前参考与历史输入副本哈希一致，均不含“课程小结”；输出也不含该内容，应记为与用户描述不一致的输入版本，而不能补造该节。未拿到用户描述的另一版本前，不宣布该预期章节已通过验收。两份历史 PDF 字符计数一致但提取顺序有差异，仍保留视觉/提取顺序复核项。

## 显式分页计划

--pagination-plan 是独立于字体 scope 的明确操作授权，接受以下对象：

```json
{
  "paragraph_groups": [[10,11,12]],
  "tables": [
    {"index":0,"repeat_header_rows":1,"keep_together":true},
    {"index":1,"repeat_header_rows":1}
  ]
}
```

段落索引为主文档 0 起始序号。组必须是正文中连续的 2—8 个段落，禁止为了关联而移动对象；允许将图片/多子图与题注、说明与公式相连。设置原生 keepNext/keepLines，保留末段既有 keepNext，不操作公式内部。域、修订、浮动、文本框等不安全组拒绝。计划不能隐式要求重写内容。

表头数量必须明确，设置连续前几行 tblHeader；行设置 cantSplit。keep_together 仅支持不超过 5 行的简单短表，通过单元格段落 keepNext 连续关联；长表不能被强制塞进一页。复杂表格、纵向合并、内嵌公式等拒绝推断。行列、合并关系和正文顺序不变。用户未明确表头或结构不可靠时，不猜测“第一行就是表头”。

内容投影仅针对计划指明对象忽略这些原生分页属性，复杂段落仍逐对象比较（只剔除已授权 keep 属性）；OMML 完整哈希和其他部件继续严格检查。格式变化逐项进入授权日志；未知或不可执行操作不能伪称通过。

真实参考副本仅将一组连续 inline 图片和明确“图/编号”题注关联；复杂/非相邻组未推断。原生分页属性不是全局最优分页算法，必须实际渲染复核。

## 渲染与宽度审计

render_docx.py 新增 --layout-checks，支持固定测试标记的同页关系、重复表头出现页、结构公式区间 bbox 和已知长公式 token 行识别。只对用户授权测试规格量测，不将原论文内容导出为写作材料。

PDF 可见字形 bbox 给出宽度下限，不是完整公式理论宽度；溢出到页面外的字形可能已被裁切。报告 visible_width_lower_bound_pt、text_area_width_pt、overflow_at_least_pt、exceeds_page 及处理原因。通用页外 bbox 检测与这些明确公式行检查并存；无法定位的公式区域为 unverified，不能按“未发现”判通过。

长公式若没有已验证的安全换行策略，就保留 OMML，不转图片、不缩字号、不拆分运行推测语义；full_layout_passed 必须为 false。当前长样本可见宽至少 506.525 pt，正文宽 415.304 pt，右侧溢出至少 91.816 pt，仍阻塞完整排版。

分式/上下标/求和/根式/矩阵/多行均使用原生结构测试。当前只保留这些对象，并检查 LibreOffice 渲染；不因 EQUATIONA/B 短文本曾居中而声称已实现复杂公式定位。根式 bbox 区间未可靠识别，保持未验证。数学字体出现 Liberation Serif/OpenSymbol；fontconfig 的 Cambria Math 回退候选与实际 PDF 字体分别报告，不能冒称原字体一致，也不擅自安装字体。

## 环境文件与验收

已确认的 Word 编辑器锁文件关闭后消失，不等同正文丢失。只对用户明确确认、原哈希精确匹配的指定锁文件生命周期作例外，保留事件记录；任何真实 DOCX/历史产物缺失或哈希变化仍失败，绝不伪造锁文件。历史清单不回写。

阶段验收见 结果报告。保真、属性、公式几何、分页、字体、Agent 抽查、用户视觉确认及 Microsoft Word 验证分别报告，未开始 Phase 4。

工具须传 `--workspace`，用户文件相对授权工作区解析；规则和资源相对安装根解析。所有原有范围授权、哈希绑定、保护与保真检查继续生效。详细入口见 [安装说明](../../INSTALL.md)。
