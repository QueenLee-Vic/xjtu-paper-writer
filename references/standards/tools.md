# 工具适配与降级

本 Skill 的可移植对象是指令与相对路径资源；不是某模型自行访问工具的能力。DeepSeek 必须运行于能加载 Skill 并提供相应工具的兼容 Agent 环境。

| 能力 | 可用时 | 不可用时 |
| --- | --- | --- |
| 文件读取 | 读取用户已授权文件、保留原件 | 说明无法读取的材料，索取关键文本 |
| 网络检索 | 核实来源及支持范围 | 使用可核查的已给文献，标明外部核实未完成 |
| 计算 | 用已有工具处理实际数据 | 给出方法或公式，不能声称已算出结果 |
| 配图 | 适配外部 Skill 或现有绘图能力 | 交付明确标识的图源/绘图说明 |
| DOCX 读写 | 使用已有文档工具及模板 | 提供正文和排版规格，明确无 DOCX 成品 |
| 文档渲染 | 检查页面与字体 | 结构检查与视觉检查分开报告 |

外部 Skill 的发现使用宿主已有的技能列表或允许读取的位置，不要求固定全局路径。外部规则与本次内容保护要求冲突时不使用冲突操作。工具失败时记录原因，尝试现有替代能力；不得自动安装软件、全局安装 Skill、修改环境配置或无限重试。

Codex CLI、Claude Code 和 DeepSeek Agent 的真实兼容性须分别验收；仅阅读这些指令不能算跨平台执行通过。


Phase 4A-1 的外部配图能力由 [配图接口](../workflow/figures.md) 区分发现、指令复核、宿主可调用和实际执行；不以目录存在或模拟声明判定真实运行通过。内置 SVG 只需标准库，PNG 依赖已有 Pillow/可加载字体；不安装或分发字体。

Phase 4A-2 数据绘图使用已有 Matplotlib/NumPy，中文/西文字体能力实际检测并记录。缺 Pandas/openpyxl 时基础 XLSX 只读解析使用 ZIP/lxml，公式/格式化或日期等不支持项停止并要求显式 CSV 导出，不猜缓存结果。DOCX 插图复用原 OOXML 保真与分页组件；详见 [科学配图接口](../workflow/scientific-figures.md)。

Phase 4B-1 的 [润色接口](../workflow/academic-polishing.md) 将模型语言编辑与 Python 保护验证分开；外部能力要求真实指令哈希、宿主接口证据、依赖和兼容性审查，不凭目录名认定成功。实际发现的 humanizer-zh-academic 有冲突规则及未验证宿主调用，默认内置；模拟可调度不算真实执行。不安装 Skill 或依赖，不承诺 AI 检测分数。


Phase 5A 使用已有 Pandoc 进行新稿转换，测试辅助仅支持实际审计的 AST 表格表示；其他版本应重新检查或停止，不将测试构造器视为跨平台 Word 写入系统。现有科学绘图/插图/润色/格式化/渲染仍按各自合同调用；当前没有安装 python-docx、额外字体或全局 Skill 来掩盖能力差异。


项目级注册和独立入口验收按 [宿主适配](project-skill-registration.md)；只在安装维护或发现问题时加载，不要求普通写作任务读取开发测试记录。


Phase 5B-2 实跑显示：宿主列出技能不等于模型加载，原生斜杠加载不等于自然选择稳定。Claude 精确 Bash 权限需匹配实际只读命令形式；OpenCode 原生 skill 返回的基目录为资源解析依据，不硬编码某个兼容入口。Humanizer 实际协同输出仍可改变科学结论，必须经过既有保护与语义审查；不因真实调用成功放行。见 跨宿主证据。


Phase 5B-2R 的诊断区分模型未选择、工具拒绝、API 错误与外层任务截止；只有记录了对应错误才能归因。测试器使用固定截止、实时接收时刻与超时进程组清理，不靠无限重试提高通过率。外部润色前置合同和失败回退详见 [润色规范](../workflow/academic-polishing.md)，它不替代原有语义检查。


## 工作区运行合同

工具须传 `--workspace`，用户文件相对授权工作区解析；规则和资源相对安装根解析。所有原有范围授权、哈希绑定、保护与保真检查继续生效。详细入口见 [安装说明](../../INSTALL.md)。
