# 02 模板分析与 07 DOCX 排版

## 决策优先级

教师明确要求 ＞ 教师提供的正式模板 ＞ 教师提供的示范案例 ＞ 用户指定的参考样式 ＞ Skill 默认样式。逐项决策，而非选择一份模板覆盖所有属性。同级冲突且影响正确性时询问；低优先级与高优先级冲突时采用高优先级，并记录差异。

分析表至少记录：属性、值、来源位置、是否明确要求。区分模板中的固定文字、填写提示、示例内容和实际样式；示例中的错误不能升级为规范。无法读取附件时不得声称已分析。

提取页面尺寸、页边距、字体及字号、段落缩进与行距、标题层级、题注、页码、封面、目录、参考文献和公式编号。已有模板优先复用其语义样式，不依靠逐段手动格式模拟标题。

## 模板分析记录与隔离

对每个属性记录：`领域(内容/格式) | 属性 | 候选值 | 来源角色及位置 | 验证状态 | 选中值 | 理由`。只在同一属性、同一适用范围内比较优先级；模板未规定的属性才向下补齐。同级互斥要求请求确认；有明确“替代旧版”的新要求才可取代旧版，不按文件时间猜测。

| 材料情况 | 处理方式 |
| --- | --- |
| 仅教师文字要求 | 提取明确内容/格式要求，未规定项用默认 |
| 教师 DOCX 模板 | 记录角色和可访问状态；调用只读分析工具提取样式属性，按输出状态区分已提取与未确定项 |
| 教师示范论文 | 学习已授权的结构/风格，不复制案例事实；其参数低于正式模板 |
| 用户参考文档 | 只在指定范围参考，低于教师要求；不能默认认定为教师模板 |
| 无模板 | 使用下表默认值，并保留来源为 Skill 默认 |

“仅参考排版”是材料使用范围限制：只可读取并继承格式属性，禁止继承主题、实验数据、观点、结论及参考文献，也不能从案例章节文字推导必写内容。格式优先级不能扩大内容编辑权限；C 模式即使模板要求新的摘要或内容标题也只报告缺项，不直接新增正文。材料角色不清晰且会改变优先级时才询问。

## 默认排版配置与来源状态

默认样式以已确认的 default-style.json 为准。用户指定的参考DOCX应另行提供，不随Skill附带；只提取排版信息，不继承文章内容。提取机制与限制见 [DOCX分析接口](docx-analysis.md)。完整默认配置采用 Skill 自定义 default 状态，部分基础参数遵循用户已确定的规范；均不得声称是从参考文件读取到的参数。消费分析结果时仍须逐项判断验证状态，不能批量把默认状态改为已验证。

默认值由 [default-style.json](default-style.json) 统一维护；合并、冲突、单位与预览的完整合同见 [样式配置解析](style-resolution.md)。默认 A4 纵向、上下 2.54 cm、左右 3.175 cm；正文宋体/TNR 五号、黑色、两端对齐、首行缩进两字。左右边距已按 Phase 3B-1 要求更新，取代先前四边 2.54 cm 的 Skill 默认方案。

总标题、三级标题、图表题注、参考文献均有独立字体/字号/对齐/行距/段前段后配置；这些配置中的标题字号、间距等已按 Phase 3B-1A 用户要求冻结为 V1.0 默认规范，不能称为原参考文件实测值。实际提取结果独立保存在 Phase 3A 配置，不随默认规范变更。

一级至三级标题保持语义层级，不强加固定章节名称或强行拆层；标题编号保留教师要求，C 模式不改编号文本。新建图表题注用一致编号，C 模式保护原编号。任何默认都不能覆盖高优先级属性；默认值与待验证状态同时记录，未验证不阻塞安全的规格设计。

## 排版交付与验证

DOCX 应使用正文、标题、图题、表题样式；设置东亚字体和西文字体，避免字体映射遗漏。保留可编辑公式、题注及表格结构，不能用截图替换公式以图省事。

仅排版比较原稿与成品的正文、数字、公式语义、图表文字、参考文献及顺序；差异必须解释并纠正，无法解释则不能通过。XML 字节变化不等于正文变化，纯文本相同也不足以证明公式无损。后续实现需兼顾段落、表格、脚注、文本框及公式等容器。

有渲染能力时检查断页、溢出、表格跨页、孤立题注及字体替换；无能力时记录未进行视觉检查。Phase 3A 已实现只读格式提取；复杂排版与自动比较程序按后续独立授权开发。


## V1.0 冻结规范与安全门槛

数值唯一来源仍为 default-style.json，本节只解释执行语义。122 项属性带 default_confirmation=user_confirmed，来源保持 skill_defaults、优先级 5；不提升为教师要求，也不升级参考文件提取状态。页眉页脚等未指定项保留原默认。四种文章共用这套基础样式，独立模块调用和教师覆盖规则不变。

正文采用 1.25 倍行距；总标题宋体 16 pt；一级、二级标题宋体 12 pt 且语义独立；三级标题宋体 10.5 pt、不加粗。标题与题注段前后为零；表格默认完整网格表，三线表仍可选。字体分开映射 East Asia 与 Latin 槽；图片居中、等比且受正文区域宽度限制，打印清晰度需要下阶段验证。

参考文献固定 13 pt 与字符悬挂缩进分别表达，禁止把倍数行距当固定值，或把旧 hanging_pt 当字符换算。公式段落对齐与公式本体/编号定位是独立配置：正文区域全宽中心与右边界为目标，不以扣除编号后的剩余区域居中。字符制表位只保存用户原单位，尚待文档度量和渲染验证；不能因默认已确认而跳过布局安全检查。具体字段互斥、兼容与接口门槛见样式配置解析规范。


Phase 3B-2A 已实现有限范围的安全直接格式写入，能力、保护及部分就绪边界见 [基础写入合同](docx-writing.md)。复杂公式定位仍不可执行，不将配置确认等同于视觉验证。


Phase 3B-2B 的实际能力与限制见 [公式和渲染](equations-rendering.md)。已验证简单公式的页面几何制表位替代方案，但原字符参数不变，复杂公式仍未就绪。


Phase 3B-2C 的缺项审计、长公式溢出阻塞及显式原生分页计划见 [分页与内容审计](pagination-audit.md)。保真通过不代表用户描述的另一参考版本已验收，数学字体和复杂公式仍保留限制。
