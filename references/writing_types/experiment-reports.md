# 实验报告默认封面与章节

仅为新写个人/小组实验报告选择默认结构；修改已有文稿、仅排版不隐含新增封面或章节。内容单元的证据要求继续按 [四类文章](types.md) 与 [真实性规范](../standards/evidence.md)，字体与页面继续按 [冻结格式](../standards/formatting.md)。

机器结构源为 [experiment-report-structure.json](../../assets/templates/experiment-report-structure.json)。它只包含封面字段/布局、成员列与章节条件，没有字体、字号、行距或页面边距。封面特殊间距和居中是 Skill 自定义位置布局，不是新参考文件实测参数；标题/字段字体等仍由既有样式解析/写入器设置。教师明确要求 ＞ 正式模板 ＞ 示范案例 ＞ 用户参考 ＞ 本默认，内容结构和排版来源分开处理。

## 封面

个人：学校文字、课程名称及个人实验报告标题、实验项目、姓名、专业、班级、学号、日期。小组：学校文字、课程名称及小组实验报告标题、实验项目、成员表（班级｜学号｜姓名）、日期。字段由本次请求动态提供，缺必需字段集中询问，不复用参考文档中的个人资料。小组按实际名单逐行生成，人数不继承源表格空白行数，不平均编造分工。

校徽可按本次用户明确授权在本地课程报告启用：只使用 assets/local/branding/ 中注册、核对哈希的原始标识，保留完整中英文校名和原比例；不额外输出重复学校名称。use_local_branding=false 可关闭；资源或本地来源记录缺失时自动回退文字学校名。任意 badge_path 仍拒绝，不允许借此使用未授权图片。Phase 5C 用户已确认随 Skill 面向本校学生课程报告及学术写作分发，范围见根目录 RESOURCE-SOURCES.md；不推定官方认证或更广泛授权。

封面原生 keepNext/keepLines 与正文首段 pageBreakBefore 保证目标分页；成员表不重建用户现有表格，而是只在全新文档按名单构造。长名称/大名单仍须实际渲染，不能只靠 XML 承诺单页。超过20名成员的输入先返回人工封面布局待办，不截断名单或删日期。封面单页仅对本次个人及三成员样例进行实际渲染验收；1/5成员另作结构生成检查，其他长度须逐文验证。

## 章节

默认语义顺序：实验目的、实验设备、实验内容、思考题、小组分工、心得与建议。仅选本次适用章节，连续编号一级标题（一、二、……），不因可选章节省略而留下五/六的固定编号。二级标题由本次实验任务提供，不默认装入有限元计算、测绘、实物测量、分析或优化等示例。

- 个人省略小组分工；小组保留该节，仅填已给贡献。缺少分工则明确待提供，不生成成员贡献，稿件保持未完成。
- 默认仅在教师确实给了思考题时保留该节，不自行编题；若教师明确强制保留该章但尚未给题目，则保留待补状态。教师给出的题目不意味着已有答案；答案也应有实际材料。
- 软件实验默认可用“实验环境与软件”；教师指定标题时保留其原要求，不自动重命名。
- 目的、设备/环境、内容、心得缺材料时用明确待提供标识，不补写设备、操作、数据、个人经历或结论。实验原理、方法、数据与分析等内容单元按任务纳入“实验内容”二级结构或教师指定章节，不丢失必要证据。
- 用户未说明个人/小组且封面选择会影响正确性时一次询问；不能根据源参考的小组封面猜人数。

## 新稿工具与边界

`scripts/build_experiment_report.py --request 请求.json --output-dir 新目录` 只构造 create 新稿；它不接受用户 DOCX，不支持已有文档改写。mode=modify/format_only 拒绝；收到 teacher_cover_template 时也拒绝用默认封面替代，应先适配教师封面。结构来源可用 structure_sources，按既有五级角色选择，同级不同章节列表阻塞；排版来源另用 style_sources 接入现有 resolver。

请求包含 article_type、cover、section_text、experiment_tasks；小组另给 members 和可选 member_contributions，教师思考题用 teacher_questions。所有文字通过 Pandoc AST 转义，只有明确提供的任务才生成二级标题。现有安装的 Pandoc AST 1.20 是当前实现边界，其他版本安全停止，不安装依赖。

工具调用既有 format_docx 进行实际默认/教师样式写入和保真检查，再仅调整新封面的 pPr 布局；逆还原证明其他 XML 不动，文字对象快照与包校验通过后才以新文件原子发布。DOCX 为待审稿，渲染与学术材料检查没有完成前不称真实报告成品。所有输出写入明确授权的独立工作区，新建目录不覆盖。

教师参考模板仅用于信息排列和章节分析，未作为二进制模板加载。源含个人资料，原 DOCX 不得公开分发；标识仅按已确认范围随包提供。运行时校验登记校徽的哈希、尺寸和限定授权；发布构建在维护侧使用显式文件白名单，学生不需要构建工具。



## 工作区运行合同

工具须传 `--workspace`，用户文件相对授权工作区解析；规则和资源相对安装根解析。所有原有范围授权、哈希绑定、保护与保真检查继续生效。详细入口见 [安装说明](../../INSTALL.md)。
