# 四类文章规则

以下是可选内容单元，不是统一必填章节。教师结构要求优先；缺少关键证据按 [真实性规范](../standards/evidence.md) 处理。只使用当前类型对应部分；修改及仅排版不按默认结构自动扩写。

## 个人实验报告

从零写作且教师未指定结构时，采用 [实验报告封面与条件章节](experiment-reports.md) 的个人默认；下表是可纳入各章节的内容单元，不另起第二套固定章节。

| 内容单元 | 写作重点 |
| --- | --- |
| 实验目的 | 对应本次实际任务、待检验关系，不先写验证成功 |
| 实验原理 | 变量、公式、适用条件及理论来源 |
| 设备与环境 | 实际仪器、软件、版本及条件；未知不臆造 |
| 方法 | 测量方案、控制变量、计算方法和复现所需参数 |
| 过程 | 实际操作与观察，不能将计划冒充已执行过程 |
| 结果 | 原始数据及可复算的派生结果，注明单位与样本 |
| 分析 | 理论/实测比较、误差来源、不确定性及解释边界 |
| 总结 | 回答目的、局限与改进建议，有证据才下结论 |

默认不强加摘要、关键词；确有外部理论或资料引用时列来源，不凑参考文献数量。数据不足交付原理、方法说明与明确待补部分，不写实测结论。可按教师结构合并结果与分析。

## 小组实验报告

继承个人实验报告的证据要求，并考虑以下内容：

- 小组信息：只使用已提供成员、组别；未知非必填时省略。
- 成员分工：记录实际贡献及信息来源，不能按人数平均虚构贡献。
- 方案设计：区分预定方案与实际执行方案，解释有记录的调整。
- 协作过程：说明测量批次、记录/操作角色及共享数据流；无记录不能编写协作细节。
- 结果与讨论：比较不同批次条件，不能无说明混合数据；保留分歧及异常。
- 小组总结：针对整体任务的证据与局限，不虚构个人心得或共识。

默认不强制摘要、关键词和贡献比例；教师要求必填而材料不足时一次询问必要信息。教师未指定时使用 [实验报告封面与条件章节](experiment-reports.md) 的小组默认；方案、过程和结果讨论可放入实验内容下，不重复同义章节。

## 课程论文

先把主题转为可论证的问题，确定范围、核心观点及证据链，再组织结构。一般可采用题目、摘要/关键词、引言、主体论证、讨论、结论及参考文献；教师可明确省略或另设章节。

新写且完全无说明时，摘要与关键词作为可配置内容默认：简短摘要及 3—5 个关键词，不冒充教师硬性要求。摘要只概括文章实际内容，不声称完成未做的实验。

引言说明问题背景和论题；主体按理论、分析或应用推进论证，区分事实与判断；讨论比较解释、反例和局限；结论回应问题，不突然加入未论证的新观点。参考文献对应实际引用，不要求虚构实证章节或创新成果。纯概念论证不必有实验数据；涉及经验性结论则必须有对应证据。

## 学术综述

定义主题、时间/学科范围与检索边界，记录实际检索来源、词项、时间及纳入排除依据；仅有用户给定集合时说明是基于该集合的综述，不能宣称覆盖全部研究。

新写无要求时可含摘要与 3—5 个关键词、引言、研究现状、分类比较、问题与局限、未来方向、结论及参考文献。未来方向须由现有缺口推导，不冒充已证实趋势。

建立比较维度：研究问题、对象/样本、方法、条件、主要发现、限制及来源位置。围绕维度组织文献，解释研究之间的联系、差异与争议；实验条件不同的结论不直接比较数值。将学界观点与作者综合判断分开，不逐篇罗列摘要。参考文献需核实，不将他人结果写成用户实验结果；只有执行了系统检索筛选才可称系统综述。
